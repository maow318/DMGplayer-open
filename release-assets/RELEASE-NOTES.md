# DMGplayer 1.0.2

Native visual DMG design and build utility for macOS.

## Download and install

1. Download **DMGplayer-1.0.2-macOS-14-universal.dmg** from the Assets section.
2. Open the DMG.
3. Drag DMGplayer into the Applications folder.

## Compatibility

- macOS 14.0 Sonoma or later
- Universal binary for Apple Silicon and Intel Macs

## Signing

This public build is ad-hoc signed and is not notarized. It contains no Apple
Developer certificate and no Developer Team identifier. On first launch, use
Finder's **Open** command or approve the app in **System Settings → Privacy &
Security** if macOS asks for confirmation.
